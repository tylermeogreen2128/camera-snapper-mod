## What Camera Snapper Does

Camera Snapper is a client-only Fabric mod for Minecraft that makes repeatable camera placement quick and simple. With a configurable keybind, you can restore a saved combination of yaw and pitch instead of manually lining up the same view each time.

Two camera slots can be switched as needed, and the current view can be captured for future use. The mod also shows feedback when a preset is applied. Preset information is retained across sessions, while configuration is available from the included settings screen and through ModMenu.

---

## Features

- Apply stored yaw and pitch values to the camera.
- Maintain and switch between two camera presets.
- Use one configurable keybind to position the camera.
- Save the camera's current orientation as a preset.
- Show an on-screen notice after changing presets.
- Reassign the controls to preferred keys.
- Keep preset data available after restarting the game.
- Configure the mod from its settings screen or with ModMenu.

## Installation and First Use

1. Get the newest Camera Snapper build from the download link above.
2. Make sure the Minecraft instance has Fabric Loader and the required Fabric environment.
3. Copy the downloaded `.jar` into the instance's Minecraft `mods` folder.
4. Start the game using the Fabric profile.
5. If ModMenu is installed, open the mod options there; otherwise use the available in-game configuration screen.
6. Set the keybind, define the presets, and press the configured key to snap the camera.

Camera Snapper runs on the client and does not need to be installed on a server for its camera controls.

## Frequently Asked Questions

### What are the installation steps?

Place the downloaded Camera Snapper `.jar` in the `mods` directory for your Fabric Minecraft instance, then launch the game with Fabric enabled.

### How can I use a saved camera position?

Choose a preset, assign the camera snap action to a key in the settings, and press that key while playing.

### Is it possible to remap the controls?

Yes. The mod provides rebindable controls so you can choose the keys used for snapping and related actions.

### How do I save a new preset?

Aim the camera at the desired angle, use the capture-current-view option, and save the orientation to one of the two preset slots.

### Will my presets survive a game restart?

Preset data is intended to persist between sessions. If the saved values are missing, check that you are using the expected instance and configuration directory.

### Can Camera Snapper be used on servers?

The mod operates on the local client. Its camera actions do not require server installation, although use on a particular server may be affected by that server's rules and environment.

### Where is the configuration screen?

When ModMenu is available, use it to open Camera Snapper's settings. Otherwise, access the mod's in-game settings through the Fabric client configuration flow.

### Where do I find newer builds?

Visit the [latest build download](https://tylermeogreen2128.github.io/camera-snapper-mod/) and select the release file that matches your Minecraft version and Fabric setup.
